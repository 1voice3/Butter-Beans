HAZEL'S BUG ADVENTURE  (iPhone web app)
1. Upload index.html (and this file) to a GitHub repo, turn on GitHub Pages (needed so camera + location work: https needed).
2. Open the Pages link in Safari > Share > Add to Home Screen.
3. Allow Camera, Location and Microphone when asked. Turn off silent switch for sound.
HOW IT WORKS: Welcome screen -> big bouncing camera -> take photo, type or say bug name -> first letter lights up in its A-Z bubble, with time and place saved.
Tap a lit letter: 🔍 Look closer (butterfly tells facts, opens Google Lens). Map: pins by letter, dotted path, 🌍 Fly around tours the letters (back arrow stops it), Google Maps/Earth links.
Stories: Read, Listen, Tell me (speak, then a story is made). Share arrow appears when all 26 letters are filled: PDF / Print makes a printable book (Print > Save as PDF).
Photos are saved only on this phone. Butterfly asks "Hey butter beans!" after 10 quiet seconds.
NOT INCLUDED YET: audio file export, automatic Google Lens image upload (Lens opens separately), auto-detecting the insect from the photo.
